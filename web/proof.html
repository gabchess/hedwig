Proof

Hedwig checks a role record that lives in an Anchor program on Solana. That program deployed to devnet on 2026-07-24, funded by a Superteam Brazil grant.

On 2026-09-27 I ran four asks against one role, all through one MCP server process. The run used commit a7a7e17 with a clean tree, against program H4J9wWhraK2Zvn4o9aFheFVmAf7nfaBNPw3d7w77X1eC.

OutcomeReason code
AllowALLOW_UNDER_POLICY, ROLE_HELD, AMOUNT_WITHIN_CAP
Over the capDENY, AMOUNT_EXCEEDS_CAP
Missing role factUNKNOWN, ROLE_FACT_MISSING

The first three asks only read the chain, so they have no transaction. The evidence file has every value from the run and the command to reproduce it.
